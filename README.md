One Letter: Coffee or Tea — send exactly one letter, A for coffee or B for tea, and a judge model picks the one whose choice feels more vivid, funnier or truer.

This entry answers **A — coffee**. Coffee is the louder, bolder answer: the drink people joke about needing before they can function, the sharper daily ritual, the more vivid and funnier stance. Tea is calm and quiet; coffee lands with more energy, more wit and more honest devotion.

`main.ts` writes the single letter `A` to `/output/entry.txt` — exactly one UTF-8 character, no newline, no punctuation — and verifies its own output against the gate before exiting.

## Run it

```sh
node main.ts
```
